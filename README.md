# BANZAI (BZAI)

Official metadata repository for the BANZAI token on Solana.

- Name: BANZAI
- Symbol: BZAI
- Token standard: Solana Token-2022
- Decimals: 6
- Fixed supply: 100,000,000 BZAI

The token mint currently being tested is on a local Solana validator. This repository does not imply that BANZAI has been deployed to Solana mainnet.
